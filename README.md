# おうちカレンダー

## 概要

家族で献立・レシピ・買い物リストを管理できるWebアプリです。

毎週iPhoneのメモアプリで献立を管理していましたが、
レシピや買い物リストとの連携が難しくなってきたため、
一元管理できるアプリとして開発しました。

## 主な機能

- 献立カレンダー
- レシピ管理
- 買い物リスト
- 栄養分析
- 家族共有
