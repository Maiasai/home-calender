# おうちカレンダー

## 概要

献立・レシピ・買い物リストをまとめて管理し、日々の料理を効率化するためのWebアプリです。

## サービス開発の経緯

普段から料理をする中で、毎週の献立と買い物リストをiPhoneのメモアプリで管理していました。

しかし、献立を考えるたびにレシピを探し直したり、必要な材料を買い物リストへ手作業で書き写したりする必要があり、管理に手間がかかっていました。
そこで、献立・レシピ・買い物リストをひとつのアプリでまとめて管理できれば、毎日の食事準備をより効率化できると考え、「おうちカレンダー」を開発しました。

## 工夫した点

### 1. デバイスごとに使いやすいUI設計

毎日使うアプリであることを意識し、PC・スマートフォンのどちらでも操作しやすいUIを目指しました。

スマートフォンでは片手でも操作しやすいようにフッターナビゲーションを採用し、PCでは一覧性を重視したレイアウトにするなど、デバイスごとの使いやすさを意識して設計しました。

### 2. 栄養分析の実装

栄養分析では、食材名や分量の表記ゆれ、男女や年齢による必要栄養量の違いなど、多くの課題がありました。

今回はまず実用性を重視し、平均的な食材サイズや栄養基準を採用することで、一定の精度を保ちながら機能として利用できる形を実装しました。

今後は、年齢や性別ごとの栄養基準への対応や、食材データの拡充を予定しています。

### 3. 入力の手間を減らす工夫

献立を登録すると、必要な材料から買い物リストを自動作成できるようにしました。

また、同じ食材は自動でまとめて表示し、ドラッグ＆ドロップで並び替えられるようにすることで、買い物時にも使いやすい画面を目指しました。

### 4. オリジナルデザイン

サービスの世界観を統一するため、ホーム画面のロゴや背景、献立カレンダー下部のイラストはすべて自作しました。

単に機能を実装するだけでなく、毎日使いたくなる親しみやすいデザインを意識し、アプリ全体の雰囲気づくりにもこだわりました。
